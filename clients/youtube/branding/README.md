# Mindbloom Branding

- **Primary color:** `#FFC700` (Mindbloom yellow)

- **Accent:** `#FFFFFF` (white)
- **Font:** Anton (display), Impact / Archivo Black (fallback)

## How to convert SVG to PNG (free, 30 sec)

**Easiest:** https://cloudconvert.com/svg-to-png
1. Upload the .svg file
2. Set width to **1080** for avatars or **2560** for banner
3. Click Convert → Download

**Alternative:** Open the .svg file in any browser → right-click → "Save as image" (Chrome/Edge).

## Where to use each

- **YouTube profile picture:** `avatar-a` exported at 1080×1080
- **YouTube banner:** `wordmark` exported at 2560×1440 (or design a wider version with the wordmark centered)
- **TikTok profile picture:** `avatar-a` exported at 200×200 (or 1080 and TikTok resizes)
- **Watermark on Shorts** (optional): tiny `avatar-a` in corner via CapCut overlay
